# Changelog

Все заметные изменения проекта. Формат — по-человечески, без строгих правил.

## 1.0.0 — 2026-11-12

Первая сборка: пять глав, шесть концовок, весь арт из IWAD.

### Добавлено

- **Конвейер ассетов** (`tools/`): чтение WAD, палитра и `COLORMAP`, патчи,
  `PATCH → PNG`, `TEXTURE1`, флэты, спрайты, DMX-звуки, MUS/MIDI → синтез,
  геометрия уровней → планы этажей, BMFont из `STCFN` и из TTF.
- **11 сцен-фонов**, собранных из текстур и флэтов: техбаза, офис, коридор,
  серверная, столовая, врата ада, адский опенспейс, храм, тронный зал, пустота,
  хранилище.
- **15 персонажей** по пять настроений у каждого (zombieman, imp, cacodemon,
  baron, revenant, arch-vile, cyberdemon, lost soul, pain elemental, mancubus,
  arachnotron, spider mastermind, chaingunner, shotgunner, demon).
- **32 плана уровней** для архива, с маркерами монстров из `THINGS`.
- **Полный GUI** из текстур WAD: текстбокс, плашки, кнопки, слайдеры, рамки,
  скан-линии, виньетка, курсор.
- **Шесть концовок**, секретная открывается бензопилой из третьей главы.
- **HUD** внутри экрана `say` — живёт ровно столько, сколько реплика.
- **Архив**: концовки, бестиарий, 32 карты с полноэкранным просмотром.
- Документация: `README`, `ASSETS`, `ARCHITECTURE`, `STORY`, `BUILD`.

### Исправлено по ходу дела (поучительное)

1. **Зерно графика превращало кадр в серый шум.** Функция `grain()` возвращала
   непрозрачный серый шум, а вызывалась через `alpha_composite` — то есть
   закрашивала весь кадр. Стало `add_grain()`: аддитивный шум по numpy.
2. **DMX-звуки звучали как статика.** Формат `3` в заголовке DMX — это
   *беззнаковые 8 бит*, а не 16. Плюс DMX отбрасывает по 16 байт паддинга
   с начала и конца. Сверено с `refs/DPTDOOM-C/doomgeneric/i_sdlsound.c`.
3. **Музыка обрывалась на коротких нотах.** Огибающая `release` длиннее самой
   ноты давала `ValueError: shapes not broadcast`. Длина атаки и релиза теперь
   ограничена длиной ноты.
4. **Bitmap-шрифты рисовались сплошными квадратами.** Ren'Py красит image-шрифты
   через `twomap → linmap`, который берёт **красный канал** как маску, а не
   альфу. Маска теперь лежит и в RGB, и в альфе — работают оба пути отрисовки.
5. **Шрифт DOOM пришлось уменьшить.** `STCFN` — это 8×7 пикселей; при
   четырёхкратном увеличении буквы слипаются в кашу. Масштабы снижены до
   2×/3×/4×, а весь интерфейс переведён на кириллический пиксельный шрифт.
6. **`Could not find font 'cyr26'`** — Ren'Py ищет image-шрифты по паре
   (имя, размер, bold, italic). Шрифты регистрируются под путём файла и во всех
   четырёх начертаниях, а размеры берутся из `game/fonts/fonts.json`.
7. **Скриншот-харнесс ловил полусломанные кадры.** `renpy.show_screen("say")`
   вручную не применяет стили `Character` — теперь используется
   `renpy.say(..., interact=False)`.

### Известные ограничения

- Модальные экраны (`chapter_card`, `map_view`) нельзя «сфотографировать»
  из скрипта: `renpy.pause()` под модальным экраном не завершается. В харнессе
  `chapter_card` поэтому не модальный.
- Звук и музыка — 8-битные 11 кГц и синтезированный MUS. Это осознанно.
- Шрифт DOOM (латиница) используется только как декоративная печать в главном
  меню: для интерфейса он слишком крупнозернистый.
