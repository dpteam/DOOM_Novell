# Ассеты: что откуда взялось

Абсолютно все изображения, звуки и шрифты в игре извлечены из IWAD
(`DOOM2.WAD` или `FREEDOOM2.WAD`) скриптами из `tools/`. В репозитории нет ни
одного нарисованного вручную файла: даже курсор и иконка приложения собраны из
палитры, текстур и спрайтов WAD.

## Как запустить конвейер

```bash
python -m pip install -r requirements.txt
python tools/build_assets.py --iwad path/to/doom2.wad --out .
```

Полная пересборка занимает ~30 секунд без музыки и несколько минут с музыкой
(синтез треков на чистом numpy — самый дорогой шаг).

Полезные флаги:

| Флаг | Что делает |
| --- | --- |
| `--iwad PATH` | путь к IWAD |
| `--out DIR` | корень проекта (там, где лежит `game/`) |
| `--skip-music` | не синтезировать музыку (быстрая пересборка интерфейса) |
| `--music-only` | пересобрать только саундтрек |
| `--ttf PATH` | TTF для кириллического шрифта (по умолчанию `tools/fonts/DejaVuSans.ttf`) |

Сборка воспроизводима: перед работой она удаляет всё, что сгенерировала
прошлая (кроме музыки при `--skip-music`), а неизменившиеся треки не
перекодирует. Кириллический шрифт лежит в репозитории
(`tools/fonts/DejaVuSans.ttf`), поэтому результат не зависит от того, какая
машина собирает.

## Соответствие lump → ассет

### Графика

| Источник в WAD | Что получается | Куда попадает |
| --- | --- | --- |
| `PLAYPAL` + `COLORMAP` | палитра и уровни освещения для всей графики | (в памяти) |
| `PNAMES` + `TEXTURE1` | композитные текстуры стен | `game/images/bg/*`, `game/gui/*` |
| `F_START..F_END` (флэты) | полы, потолки, «металл» для панелей | фоны, `gui/` |
| `S_START..S_END` (спрайты) | персонажи (5 настроений), предметы, декор | `game/images/chars`, `game/images/items`, `game/images/ui/prop_*` |
| `STCFN*` (патчи) | шрифт DOOM (латиница, цифры) в трёх масштабах | `game/fonts/doom1|2|3.fnt` |
| `TITLEPIC` | постер главного меню | `game/gui/main_menu.png` |
| `M_DOOM` | логотип для иконки | `icon.ico` / `icon.png` |
| `MAP01..MAP32` (`VERTEXES`, `LINEDEFS`, `SIDEDEFS`, `SECTORS`, `THINGS`) | планы этажей: заливка секторов цветом пола, маркеры монстров | `game/images/maps/mapNN.png`, карточки глав |

### Звук

| Источник | Что получается |
| --- | --- |
| `DS*` (DMX-сэмплы) | WAV-эффекты: выстрел, дробовик, хлюп, дверь, взрыв, боль, предмет, пила, телепорт |
| `D_*` (MUS или MIDI) | OGG-треки: `title`, `map`, `office`, `chase`, `hell`, `boss`, `ending` |

Музыка не конвертируется «как есть»: MUS разбирается в события, а затем
рендерится собственным аддитивным синтезатором (`tools/wadlib/audio.py`).
Звучит это как звуковая карта 1994 года, у которой случился конфликт с
блендером — что для DOOM-новеллы ровно то, что нужно. Если в системе есть
`ffmpeg`, результат дополнительно пакуется в OGG.

отсутствующий кадр у какого-нибудь монстра не ломает сборку.

## Сцены

`game/images/bg/*.png` — 11 «сцен-коробок»: техбаза, офис, коридор, серверная,
столовая, врата ада, адский опенспейс, храм, тронный зал, пустота, хранилище.
Каждая собрана из:

1. текстур стен (`TEXTURE1`) — задняя стена и боковины;
2. флэтов — пол и потолок;
3. двери (тоже текстура);
4. спрайтов-декора (бочки, черепа, лампы);
5. пост-обработки: градиенты, засветка, туман, виньетка, скан-линии, зерно.

## Шрифты

| Имя | Источник | Размер (px) | Где используется |
| --- | --- | --- | --- |
| `doom1` | `STCFN` ×2 | 14 | декоративная печать `RIP AND TEAR / FAN BUILD` |
| `doom2` | `STCFN` ×3 | 21 | зарезервирован под латинские подписи |
| `doom3` | `STCFN` ×4 | 28 | крупные латинские заголовки |
| `cyr20` | DejaVu Sans, без сглаживания | 20 | интерфейс, мелкий текст, HUD |
| `cyr26` | DejaVu Sans | 26 | диалоги |
| `cyr32` | DejaVu Sans | 32 | имена, значения HUD |
| `cyr44` | DejaVu Sans | 44 | заголовки меню, главы |

Почему два набора: в шрифте DOOM нет кириллицы, а игра на русском. Поэтому
кириллица растрируется из DejaVu Sans в 1-битном режиме (без сглаживания) —
получается тот же пиксельный вид. Латиница и цифры остаются оригинальными,
но только там, где хватает разрешения: `STCFN` — это 8×7 пикселей, и при
увеличении больше чем в 2–3 раза буквы слипаются.

**Важно:** это bitmap-шрифты. Их нельзя рисовать «другим размером» — Ren'Py
регистрирует шрифт под точной парой (имя, размер). Все размеры в стилях
привязаны к значениям из `game/fonts/fonts.json`, который пишет конвейер.
Если нужен новый размер — добавьте его в `build_assets.py`, пересоберите
шрифты и только потом используйте в стилях.

В Ren'Py 8.5 это стало жёстким требованием: `{size=N}` в тексте для
bitmap-шрифта роняет игру с `FreetypeError: unknown file format`. Никаких
`{size=...}` — только отдельные стили под каждый кегль.

Шрифты регистрируются **под путём файла** (`fonts/cyr26.fnt`), а не под
коротким именем: так `renpy lint` видит существующий файл и не заваливает
отчёт предупреждениями «not loadable». Регистрация делается для всех четырёх
комбинаций bold/italic, чтобы случайное `bold True` не ломало сцену.

Атлас глифов хранит маску **и в RGB, и в альфа-канале**: Ren'Py красит
image-шрифты через `twomap → linmap`, который в качестве маски берёт красный
канал, а прямой blit (для чисто белого текста) — альфу. Если заполнить только
альфу, весь текст превращается в сплошные прямоугольники.

## Манифест

`game/wad_manifest.json` фиксирует, из какого файла что собрано: SHA-256 IWAD,
список карт, счётчики, время сборки. Он же попадает в архив при упаковке —
удобно, если хочется доказать, что ассеты не «нарисованы руками».

## Лицензии

- Код, скрипты и конвейер — MIT (см. `LICENSE`).
- Графика и звук — id Software / ZeniMax. Проект фанатский и некоммерческий.
- **Публичные сборки делаются из FreeDoom**, а не из DOOM2.WAD: релизный
  workflow пересобирает ассеты из `freedoom2.wad` (BSD) и проверяет манифест
  внутри архива перед публикацией. Локально:

  ```bash
  python tools/build_assets.py --iwad freedoom2.wad --out .
  ```

  Или, если нужен полный проект из FreeDoom-ассетов, с проверками:

  ```bash
  python tools/make_freedoom_build.py --assets <куда собрали> --out <проект>
  ```

- Кириллические шрифты — растрированные глифы DejaVu Sans (Bitstream Vera).

### Что меняется в FreeDoom-сборке

Ничего в коде: те же главы, шутки и выборы. Меняются спрайты, текстуры,
звуки, музыка и планы уровней — FreeDoom рисует свою «адскую корпорацию».
Экран «О проекте» показывает, из какого IWAD собран билд, так что подмену
видно сразу.
